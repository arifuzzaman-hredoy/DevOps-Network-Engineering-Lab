# Network Engineering & Troubleshooting Lab

A practical, hands-on networking project designed to build the networking knowledge and troubleshooting skills required for a Junior DevOps Engineer.

## Project Overview

This repository documents practical networking concepts, Linux networking commands, IP addressing, subnetting, DNS resolution, TCP/UDP communication, routing, firewall configuration, and packet analysis.

The project focuses on understanding how clients, servers, applications, and network services communicate in real-world DevOps environments.

## Learning Objectives

- Understand OSI and TCP/IP models.
- Configure and inspect IP addressing.
- Practice subnetting and CIDR calculations.
- Investigate DNS resolution problems.
- Understand TCP, UDP, and network ports.
- Analyze HTTP/HTTPS communication.
- Understand routing, NAT, and firewalls.
- Capture and analyze packets using tcpdump and Wireshark.
- Troubleshoot real-world network connectivity issues.

## Technology Stack

- Ubuntu Linux
- WSL2
- Bash
- Wireshark
- tcpdump
- Docker
- UFW
- Git & GitHub
